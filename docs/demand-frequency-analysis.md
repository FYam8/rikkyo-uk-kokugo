# Cross-exam observed demand frequency

Basis: 142 visible parent questions in the supplied FY24–FY26 A/B problem booklets. FY24-B I/II are copyright-omitted and therefore excluded. A parent question can carry multiple demand tags, so counts are not percentages and do not sum to 142.

## Most repeated observed demands

- KANJI: 47 parent questions
- CONTENT_SELECTION: 28 parent questions
- TEXT_EXTRACTION: 24 parent questions
- VOCAB_CONTEXT: 19 parent questions
- LITERARY_CHARACTER: 19 parent questions
- BLANK_COMPLETION: 17 parent questions
- WRITTEN_EXPLANATION: 17 parent questions
- PHRASE_INTERPRETATION: 8 parent questions
- LOGIC_RELATION: 8 parent questions
- CONCEPT_EXPLANATION: 4 parent questions

## Interpretation

The visible set repeatedly combines knowledge with reading-process demands. The most common non-kanji tags are content-selection, text extraction, vocabulary-in-context, literary character/feeling, blank completion and written explanation.

This supports a Rikkyo repair model that separates at least:
- knowledge/kanji-vocabulary,
- finding and extracting evidence,
- checking choices against the text,
- literary character/feeling,
- logical/blank relation,
- constrained written explanation.

These are still **observed demand families**, not scored weakness diagnoses. A wrong answer can have a different cause from the surface task type, so diagnosis rules remain blocked until answer/scoring authority and error-cause rules are established.

## A/B handling

The data does not justify a separate A-only or B-only engine. Both schedules use the same broad families. A/B remains exam data/identity, while UI/UX and learning mechanics stay shared.
